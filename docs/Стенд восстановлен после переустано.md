ВАЖНОЕ ПРО СТЕНД — в главу 3
Схема электропитания Windows влияет сильнее, чем измеряемый эффект.
Контрольный замер: 262.3 RPS при схеме «Сбалансированная» против
604.7 RPS при «Высокая производительность» — расхождение в 2.3 раза,
больше любого различия между сравниваемыми ветками. В описании
стенда фиксирую схему питания как параметр конфигурации.

Стенд: DESKTOP-BQH0GN7, AMD Ryzen 5 5600U, WSL2 (6 логических
процессоров = 3 физических ядра с SMT, 5.8 ГБ), схема питания —
высокая производительность. Параметры прежние: -t2 -c10, прогрев +
3 прогона по 30с. Разброс внутри серий 0.5–5.7%.
